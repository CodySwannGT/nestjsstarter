# Project Knowledge

This project carries an in-repo LLM Wiki maintained by the `lisa-wiki` kernel.

- Durable knowledge lives in `wiki/`. Start at `wiki/start-here.md`.
- The rules the wiki follows are in `wiki/schema/llm-wiki-contract.md`.
- Navigation map: `wiki/index.md`. Operation log: `wiki/log.md`.

Use `/query "<question>"` for cited answers, `/ingest <url|file|prompt>` (or `/ingest` with no
argument for a full ingest) to add knowledge, and `/onboard-me` for a guided tour.
